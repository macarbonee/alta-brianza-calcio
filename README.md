# Alta Brianza Calcio

App della squadra Esordienti U12 di Alta Brianza Tavernerio.

- Si installa su iPhone da Safari: **Condividi → Aggiungi alla schermata Home**.
- I dati (rosa, calendario, risultati, formazioni) stanno nel database Supabase e si vedono solo dopo l'accesso: in questo repository non c'è nessun dato della squadra.
- `config.js` contiene l'indirizzo del progetto Supabase e la sua chiave pubblica.
